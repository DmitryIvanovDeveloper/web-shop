### Overview
Create a new marketing campaign based on communication type and template.

Preconditions:
- User is logged in
- Permission to create campaigns

Scenario (USER ACTION => SYSTEM REACTIONS):
1. User selects communication type and template =>
  - System prepares the campaign form
2. User fills in name, description, start/end dates =>
  - Draft campaign is saved

Expected Final State:
- Draft campaign created with basic configuration
