### Overview
Manage support tickets: creation, prioritization, and status changes.

Preconditions:
- User is logged in
- Access to support module

Scenario (USER ACTION => SYSTEM REACTIONS):
1. User creates a ticket (subject, priority) =>
  - Ticket is added and assigned a status
2. User changes ticket status (in progress/closed) =>
  - State is updated and visible in the list

Expected Final State:
- Support request registered and under control
