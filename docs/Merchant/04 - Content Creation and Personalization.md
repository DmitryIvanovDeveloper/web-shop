### Overview
Create campaign content and configure personalization.

Preconditions:
- User is logged in
- Campaign in draft status

Scenario (USER ACTION => SYSTEM REACTIONS):
1. User configures message (subject, CTA) =>
  - System prepares content for communication
2. User adds media (banner/video) =>
  - Content updated with assets
3. User sets personalization (discounts, A/B) =>
  - Personalization parameters saved

Expected Final State:
- Campaign content prepared with personalization settings
