### Overview
Create a custom report with selected metrics and output format.

Preconditions:
- User is logged in
- Access to Reporting module

Scenario (USER ACTION => SYSTEM REACTIONS):
1. User sets date range and metrics =>
  - System prepares a report draft
2. User chooses format (PDF/Excel/CSV) =>
  - System prepares export
3. User confirms generation =>
  - Downloadable file becomes available

Expected Final State:
- Report is created and available for download
