### Overview
Monitor mobile app metrics and identify performance issues.

Preconditions:
- User is logged in
- Access to mobile analytics

Scenario (USER ACTION => SYSTEM REACTIONS):
1. User reviews key metrics (sessions, duration, crash rate) =>
  - System highlights problem areas via cards/lists
2. User flags areas for investigation =>
  - A focus list is formed

Expected Final State:
- Plan of action for performance improvements is formed
