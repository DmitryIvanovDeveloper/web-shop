### Overview
Analyze a data anomaly and identify root causes.

Preconditions:
- User is logged in
- Access to the analytics dashboard

Scenario (USER ACTION => SYSTEM REACTIONS):
1. User opens the anomaly alert =>
  - Details and key indicators are displayed
2. User drills down by region/category/segment =>
  - System shows each factor's contribution
3. User marks the incident as reviewed =>
  - Anomaly moves to the incident history

Expected Final State:
- Incident recorded; causes and impact are understood
