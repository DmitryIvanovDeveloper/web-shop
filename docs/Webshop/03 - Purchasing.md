### Overview
Complete a purchase by providing contact and payment details.

Preconditions:
- User is logged in
- User has verified identity

Scenario (USER ACTION => SYSTEM REACTIONS):
1. User fills email, payment method, and quantity =>
  - System calculates the total and validates inputs
2. User confirms purchase =>
  - Items are added to the account; confirmation shown

Expected Final State:
- Purchase is completed and recorded
