# Abandoned Cart Offers - Предложения для брошенных корзин

*Система автоматических предложений и напоминаний для игроков, которые добавили товары в корзину, но не завершили покупку*

---

## 🎯 Обзор Abandoned Cart Offers

Abandoned Cart Offers - это система автоматических уведомлений и персонализированных предложений для игроков, которые начали процесс покупки, но не завершили его. Система анализирует поведение игроков и отправляет целевые предложения для стимулирования завершения покупки.

### Основные возможности:
- **Автоматическое обнаружение** - выявление брошенных корзин
- **Персонализированные предложения** - индивидуальные скидки и бонусы
- **Многоуровневые напоминания** - серия уведомлений с разными подходами
- **Аналитика эффективности** - отслеживание конверсии и ROI

---

## 🛒 Типы брошенных корзин

### ⏰ По времени брошения
- **Немедленные** - корзина брошена в течение 5 минут
- **Краткосрочные** - брошена 15-30 минут назад
- **Среднесрочные** - брошена 1-6 часов назад
- **Долгосрочные** - брошена более 24 часов назад

### 💰 По стоимости корзины
- **Низкая стоимость** - до $10
- **Средняя стоимость** - $10-50
- **Высокая стоимость** - $50-100
- **Премиум** - более $100

### 🎮 По типу контента
- **Скины персонажей** - косметические предметы
- **Оружие и снаряжение** - игровые улучшения
- **Боевые пропуски** - сезонный контент
- **Наборы и бандлы** - комплекты предметов

### 👥 По типу игрока
- **Новые игроки** - первая покупка
- **Опытные игроки** - регулярные покупатели
- **VIP игроки** - высокоценные клиенты
- **Неактивные** - давно не покупали

## 🎯 Сценарии использования Abandoned Cart Offers

### **Сценарий 1: "Первое напоминание для новой корзины"**
*Как система реагирует на брошенную корзину новичка*

**Что происходит:**
1. **Обнаружение брошенной корзины:**
   - Игрок добавил скин за $9.99 в корзину
   - Прошло 10 минут без активности
   - Игрок покинул магазин
   - Система классифицирует как "брошенная корзина"

2. **Анализ игрока:**
   - Сегмент: "Новый игрок (регистрация < 7 дней)"
   - История покупок: "Нет предыдущих покупок"
   - Поведение: "Интерес к косметическим скинам"
   - Риск оттока: "Средний"

3. **Персонализированное предложение:**
   - Время отправки: "Через 30 минут"
   - Канал: "Push-уведомление в игре"
   - Предложение: "Скидка 15% на выбранный скин"
   - Дополнительно: "Бесплатная эмодзи в подарок"

**📊 Какие данные используются:**
- **🛒 Данные о корзине** - содержимое, стоимость, время добавления
- **👥 Данные об игроке** - сегмент, история покупок, поведение
- **🎯 Персонализационные данные** - предпочтения, интересы
- **📈 Аналитические данные** - эффективность подобных предложений

### **Сценарий 2: "Эскалация для высокоценной корзины"**
*Как система реагирует на брошенную дорогую корзину*

**Что происходит:**
1. **Обнаружение премиум корзины:**
   - Игрок добавил набор скинов за $89.99

   - **Уровень 3 (через 24 часа):** "Персональное предложение от менеджера"

3. **Персонализация под VIP:**
   - Персональное сообщение
   - Эксклюзивные бонусы
   - Приоритетная поддержка
   - Возможность рассрочки

**📊 Какие данные используются:**
- **💰 Финансовые данные** - стоимость корзины, история трат
- **👑 VIP статус** - уровень клиента, привилегии
- **📈 Поведенческие данные** - предпочтения в покупках
- **🎯 Персонализационные данные** - индивидуальные предложения

### **Сценарий 3: "Реактивация долгосрочной корзины"**
*Как вернуть игрока, который бросил корзину несколько дней назад*

**Что происходит:**
1. **Анализ долгосрочной корзины:**
   - Корзина брошена 3 дня назад
   - Содержимое: "Сезонный боевой пропуск"
   - Игрок неактивен с момента брошения
   - Риск полной потери клиента

2. **Специальная стратегия реактивации:**
   - **Email кампания:** "Мы скучаем по вам"
   - **Игровое уведомление:** "Особое предложение для возвращения"
   - **Социальная реклама:** "Таргетированная реклама в соцсетях"

3. **Агрессивные предложения:**
   - Скидка до 40%
   - Эксклюзивный контент
   - Бонусы за возвращение
   - Ограниченное время действия

**📊 Какие данные используются:**
- **⏰ Временные данные** - время брошения, период неактивности
- **📧 Контактные данные** - email, социальные сети
- **🎮 Игровые данные** - предпочтения, активность
- **📊 Исторические данные** - эффективность реактивации

## 📋 Модели данных Abandoned Cart Offers

### 🛒 Данные о брошенных корзинах

**Что хранится:**
- **Идентификатор корзины** - уникальный ID
- **Игрок** - информация о владельце корзины
- **Содержимое** - товары в корзине
- **Время создания** - когда корзина была создана
- **Время брошения** - когда игрок покинул корзину
- **Стоимость** - общая стоимость корзины

**Пример данных:**
```
Корзина: "CART_789456"
Игрок: "CyberNinja_2024"
Содержимое:
  - "Неоновый воин - Скин": "$9.99"
  - "Кибер-меч": "$15.99"
  - "Боевой пропуск": "$24.99"
Время создания: "15 января 2024, 14:30"
Время брошения: "15 января 2024, 14:45"
Общая стоимость: "$50.97"
Статус: "Активная (ожидает напоминания)"
```

**Как используется:**
- Для анализа паттернов брошения корзин
- Для создания персонализированных предложений
- Для оптимизации процесса покупки
- Для расчета потенциального дохода

### 📧 Данные о напоминаниях и предложениях

**Что хранится:**
- **Тип напоминания** - push, email, in-game
- **Время отправки** - когда было отправлено
- **Содержание** - текст и предложения
- **Реакция игрока** - открыл, кликнул, купил
- **Эффективность** - конверсия напоминания

**Пример данных:**
```
Напоминание: "REMINDER_001"
Корзина: "CART_789456"
Тип: "Push-уведомление"
Время отправки: "15 января 2024, 15:15"
Содержание:
  - Заголовок: "Не забудьте про выбранные скины!"
  - Текст: "У вас в корзине товары на $50.97"
  - Предложение: "Скидка 15% + бесплатная эмодзи"
Реакция:
  - Открыто: "Да"
  - Клик: "Да"
  - Покупка: "Да"
  - Конверсия: "100%"
```

**Как используется:**
- Для оптимизации содержания напоминаний
- Для выбора оптимального времени отправки
- Для A/B тестирования различных подходов
- Для расчета ROI кампаний

### 📊 Данные об эффективности системы

**Что хранится:**
- **Общая статистика** - количество брошенных корзин
- **Конверсия по типам** - эффективность разных подходов
- **Временная аналитика** - когда чаще бросают корзины
- **Сегментная аналитика** - эффективность по группам игроков

**Пример данных:**
```
Период: "Январь 2024"
Общая статистика:
  - Брошенных корзин: "15,247"
  - Напоминаний отправлено: "45,741"
  - Конверсия: "23.4%"
  - Восстановленный доход: "$127,890"
По типам корзин:
  - Низкая стоимость: "31% конверсия"
  - Средняя стоимость: "28% конверсия"
  - Высокая стоимость: "35% конверсия"
  - Премиум: "42% конверсия"
```

**Как используется:**
- Для оценки общей эффективности системы
- Для оптимизации стратегий по типам корзин
- Для планирования бюджета на кампании
- Для сравнения с industry benchmarks

## 📈 Ключевые метрики Abandoned Cart Offers

### Основные показатели
- **Abandonment Rate** - процент брошенных корзин от общих
- **Recovery Rate** - процент восстановленных корзин
- **Conversion Rate** - конверсия напоминаний в покупки
- **Revenue Recovery** - восстановленный доход от системы

### Эффективность кампаний
- **Open Rate** - процент открытых уведомлений
- **Click-Through Rate** - процент кликов по предложениям
- **Purchase Rate** - процент завершенных покупок
- **Average Order Value** - средний чек восстановленных покупок

### Операционные метрики
- **Response Time** - время от брошения до первого напоминания
- **Campaign Duration** - длительность кампании восстановления
- **Channel Performance** - эффективность разных каналов
- **Cost Per Recovery** - стоимость восстановления одной корзины
