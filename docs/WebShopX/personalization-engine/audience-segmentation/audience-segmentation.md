# Audience Segmentation - Сегментация игроков

*Система автоматической сегментации игроков по поведению, характеристикам и риску оттока*

---

## 🎯 Обзор Audience Segmentation

Audience Segmentation - это AI-система для автоматического разделения игроков на группы на основе их поведения, характеристик и предсказанных рисков. Система использует машинное обучение для создания точных сегментов и предоставляет детальную аналитику по каждой группе.

### Основные возможности:
- **Автоматическая сегментация** - ML-алгоритмы для группировки игроков
- **RFM анализ** - Recency, Frequency, Monetary сегментация
- **Географическая сегментация** - группировка по странам и регионам
- **Предсказание оттока** - ML-модели для определения риска ухода игроков

---

## 👥 Типы сегментации

### 🎯 RFM анализ (Recency, Frequency, Monetary)
- **Recency** - как давно игрок был активен
- **Frequency** - как часто игрок заходит в игру
- **Monetary** - сколько денег тратит игрок
- **Комбинированные сегменты** - пересечение всех трех параметров

### 🌍 Географическая сегментация
- **Страны** - группировка по государствам
- **Регионы** - континенты, экономические зоны
- **Часовые пояса** - активность по времени
- **Языки** - предпочтения по локализации

### 💰 Сегментация по доходности (ARPU)
- **High Value** - игроки с высоким ARPU
- **Medium Value** - средняя доходность
- **Low Value** - низкая доходность
- **Non-Paying** - не платящие игроки

### ⚠️ Сегментация по риску оттока
- **Низкий риск** - стабильные игроки
- **Средний риск** - требуют внимания
- **Высокий риск** - нужны удержательные меры
- **Уже ушедшие** - для reactivation кампаний

## 🎯 Сценарии использования Audience Segmentation

### **Сценарий 1: "Автоматическая сегментация новых игроков"**
*Как система автоматически классифицирует новичков*

**Что происходит:**
1. **Сбор данных о новом игроке:**
   - География: "США, Калифорния"
   - Источник: "Facebook реклама"
   - Первые действия: "Просмотр скинов, добавление в корзину"
   - Время игры: "45 минут в первый день"

2. **ML-анализ и сегментация:**
   - RFM анализ: "Новый игрок (R=0, F=1, M=0)"
   - Географический сегмент: "Северная Америка, высокий ARPU"
   - Поведенческий сегмент: "Интерес к косметике"
   - Прогноз: "Высокий потенциал покупок"

3. **Автоматическое назначение сегмента:**
   - Сегмент: "High-Potential Newcomer"
   - Стратегия: "Персонализированные предложения скинов"
   - Приоритет: "Высокий для retention"

**📊 Какие данные используются:**
- **👥 Данные об игроках** - регистрация, география, источник
- **🎮 Поведенческие данные** - первые действия в игре
- **📊 ML модели** - предсказание потенциала игрока
- **📈 Исторические данные** - похожие игроки и их развитие

### **Сценарий 2: "Выявление игроков с высоким риском оттока"**
*Как система предсказывает, кто может уйти из игры*

**Что происходит:**
1. **Мониторинг поведения игрока:**
   - Снижение активности: "Было 2 часа/день, стало 20 минут"
   - Редкие покупки: "Последняя покупка 3 недели назад"
   - Социальная активность: "Не играет с друзьями"
   - Время в игре: "Короткие сессии, быстрые выходы"

2. **ML-анализ риска оттока:**
   - Модель churn prediction: "85% вероятность ухода"
   - Факторы риска: "Низкая активность, отсутствие покупок"
   - Временной прогноз: "Уход в течение 7 дней"
   - Рекомендации: "Срочные удержательные меры"

3. **Автоматическое назначение сегмента:**
   - Сегмент: "High Churn Risk"
   - Стратегия: "Экстренные удержательные предложения"
   - Каналы: "Email + Push + In-game"

**📊 Какие данные используются:**
- **🤖 ML модели** - предсказание оттока на основе поведения
- **📈 Поведенческие данные** - активность, покупки, социальные взаимодействия
- **⏰ Временные данные** - изменения в паттернах поведения
- **📊 Аналитические данные** - сравнение с похожими игроками

### **Сценарий 3: "Создание VIP сегмента для премиум игроков"**
*Как выделить самых ценных игроков для особого обслуживания*

**Что происходит:**
1. **Анализ ценности игроков:**
   - LTV анализ: "Игроки с LTV > $500"
   - Частота покупок: "Регулярные покупатели"
   - Социальное влияние: "Активные в сообществе"
   - Лояльность: "Долгосрочные игроки (1+ год)"

2. **Создание VIP сегмента:**
   - Критерии: "LTV > $500 + активность > 6 месяцев"
   - Размер сегмента: "Топ 5% игроков"
   - Характеристики: "Высокая лояльность, влиятельность"
   - Потенциал: "Рекомендации другим игрокам"

3. **Специальные условия для VIP:**
   - Персональный менеджер
   - Эксклюзивный контент
   - Приоритетная поддержка
   - Участие в бета-тестировании

**📊 Какие данные используются:**
- **💰 Финансовые данные** - LTV, ARPU, история покупок
- **👥 Социальные данные** - влияние в сообществе, рекомендации
- **⏰ Данные лояльности** - время в игре, регулярность активности
- **📊 Сегментационные данные** - сравнение с другими игроками

## 📋 Модели данных Audience Segmentation

### 👥 Данные о сегментах игроков

**Что хранится:**
- **Название сегмента** - "High-Value Active Players"
- **Критерии сегментации** - параметры для попадания в сегмент
- **Размер сегмента** - количество игроков
- **Характеристики** - типичные черты сегмента
- **Динамика** - изменение размера сегмента

**Пример данных:**
```
Сегмент: "Whale Players"
Критерии:
  - ARPU: "> $200/месяц"
  - Активность: "> 20 часов/неделю"
  - Лояльность: "> 6 месяцев в игре"
Размер: "1,247 игроков (0.8%)"
Характеристики:
  - Средний LTV: "$3,450"
  - Частота покупок: "2.3 раза/неделю"
  - Любимые категории: "Эксклюзивные скины, боевые пропуски"
Динамика:
  - Рост за месяц: "+15%"
  - Удержание: "94%"
```

**Как используется:**
- Для создания персонализированных кампаний
- Для планирования контента под сегменты
- Для анализа эффективности сегментации
- Для оптимизации монетизации

### 📊 Данные RFM анализа

**Что хранится:**
- **Recency Score** - балл за недавность активности
- **Frequency Score** - балл за частоту активности
- **Monetary Score** - балл за траты
- **Комбинированный RFM** - итоговый сегмент
- **История изменений** - динамика RFM показателей

**Пример данных:**
```
Игрок: "CyberNinja_2024"
RFM Анализ:
  - Recency: "5 (активен сегодня)"
  - Frequency: "4 (играет 5-6 раз/неделю)"
  - Monetary: "5 (тратит > $100/месяц)"
  - RFM Сегмент: "Champions (555)"
  - Тренд: "Стабильный высокий уровень"
История:
  - 3 месяца назад: "New Customers (455)"
  - 2 месяца назад: "Potential Loyalists (544)"
  - 1 месяц назад: "Loyal Customers (554)"
  - Текущий: "Champions (555)"
```

**Как используется:**
- Для понимания жизненного цикла игроков
- Для создания targeted кампаний
- Для прогнозирования поведения
- Для оптимизации retention стратегий

### 🤖 Данные ML моделей сегментации

**Что хранится:**
- **Тип модели** - алгоритм сегментации
- **Входные данные** - признаки для анализа
- **Параметры модели** - настройки алгоритма
- **Точность** - качество сегментации
- **Результаты** - предсказанные сегменты

**Пример данных:**
```
Модель: "K-Means Clustering"
Входные данные:
  - Поведенческие: "время игры, частота покупок"
  - Демографические: "возраст, страна, устройство"
  - Игровые: "уровень, достижения, социальная активность"
Параметры:
  - Количество кластеров: "8"
  - Итерации: "100"
  - Метрика: "Euclidean distance"
Точность: "87.3%"
Сегменты:
  - "Casual Gamers": "2,456 игроков"
  - "Hardcore Players": "1,234 игрока"
  - "Social Players": "987 игроков"
  - "Whales": "156 игроков"
```

**Как используется:**
- Для автоматической сегментации больших объемов данных
- Для выявления скрытых паттернов поведения
- Для создания новых типов сегментов
- Для оптимизации алгоритмов сегментации

## 📈 Ключевые метрики Audience Segmentation

### Метрики сегментации
- **Количество сегментов** - общее число активных сегментов
- **Размер сегментов** - средний размер группы игроков
- **Качество сегментации** - точность ML моделей
- **Скорость обновления** - время пересчета сегментов

### Эффективность сегментов
- **Segmentation Accuracy** - точность попадания в сегменты
- **Segment Stability** - стабильность сегментов во времени
- **Business Impact** - влияние сегментации на бизнес-метрики
- **Campaign Performance** - эффективность targeted кампаний

### ML метрики
- **Model Accuracy** - точность ML моделей
- **Training Time** - время обучения моделей
- **Prediction Speed** - скорость предсказаний
- **Feature Importance** - важность признаков для сегментации
