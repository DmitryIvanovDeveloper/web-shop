# Promo/Offer Management - Управление промо и предложениями

*Система создания и управления промо-кодами, скидками, бонусами и специальными предложениями*

---

## 🎯 Обзор Promo/Offer Management

Promo/Offer Management - это комплексная система управления всеми типами промо-активностей в игровом магазине. Система позволяет создавать гибкие предложения, настраивать сложные условия и автоматизировать запуск промо-кампаний для максимизации конверсии и удержания игроков.

### Основные возможности:
- **Flow Editor** - визуальный редактор промо-цепочки
- **Гибкие условия** - сложные правила активации предложений
- **Автоматизация** - запуск по событиям и расписанию
- **A/B тестирование** - оптимизация эффективности предложений

---

## 🎁 Типы промо-предложений

### Скидки и бонусы
- **Процентные скидки** - 10%, 20%, 50% на категории товаров
- **Фиксированные скидки** - $5, $10, $20 с покупки
- **Бесплатные предметы** - подарки при покупке
- **Двойные бонусы** - увеличение игровой валюты

### Промо-коды
- **Одноразовые коды** - для конкретного игрока
- **Многоразовые коды** - для группы игроков
- **Ограниченные коды** - с лимитом использований
- **Временные коды** - действующие определенный период

### Специальные предложения
- **Бандлы** - комплекты товаров со скидкой
- **Персональные предложения** - индивидуальные для игрока
- **Сезонные акции** - приуроченные к событиям
- **Реферальные программы** - за привлечение друзей

### Игровые события
- **Лимитированные предложения** - эксклюзивный контент
- **Временные события** - ограниченные по времени
- **Уровневые бонусы** - за достижения в игре
- **Лояльность** - накопительные программы

## 🎯 Сценарии использования Promo/Offer Management

### **Сценарий 1: "Создание персонализированного предложения для возвращения игрока"**
*Как создать специальное предложение для неактивного игрока*

**Что происходит:**
1. **Анализ игрока:**
   - История покупок и предпочтений
   - Время последней активности
   - Любимые категории предметов
   - Средняя сумма покупок

2. **Создание персонализированного предложения:**
   - Выбор типа скидки (процент или фиксированная)
   - Определение размера скидки (на основе истории)
   - Выбор товаров для предложения
   - Настройка условий активации

3. **Настройка доставки:**
   - Выбор канала (email, push, in-game)
   - Определение времени отправки
   - Создание персонализированного сообщения
   - Настройка напоминаний

**📊 Какие данные используются:**
- **👥 Данные об игроках** - история покупок, предпочтения, активность
- **🎮 Данные о предметах** - популярные товары игрока
- **💰 Данные о промо** - эффективность различных типов предложений
- **📈 Данные о продажах** - для определения оптимального размера скидки

### **Сценарий 2: "Запуск сезонной акции с ограниченным предложением"**
*Как создать и запустить крупную сезонную промо-кампанию*

**Что происходит:**
1. **Планирование акции:**
   - Определение темы и концепции
   - Выбор товаров для участия в акции
   - Настройка уровней скидок
   - Создание временных рамок

2. **Настройка промо-цепочки:**
   - Создание многоуровневых предложений
   - Настройка условий прогрессии
   - Подготовка эксклюзивного контента
   - Создание системы наград

3. **Запуск и мониторинг:**
   - Активация всех компонентов акции
   - Отслеживание участия игроков
   - Корректировка условий в реальном времени
   - Анализ эффективности по сегментам

**📊 Какие данные используются:**
- **🎯 Данные о игровых событиях** - сезонные активности
- **💰 Данные о промо** - статистика использования предложений
- **📈 Данные о продажах** - доходы от сезонных акций
- **🌍 Географические данные** - региональные предпочтения

### **Сценарий 3: "A/B тестирование различных типов предложений"**
*Как оптимизировать эффективность промо-предложений*

**Что происходит:**
1. **Создание вариантов для тестирования:**
   - Разные размеры скидок (10%, 20%, 30%)
   - Различные типы предложений (процент, фиксированная сумма)
   - Разные условия активации
   - Различные способы презентации

2. **Настройка A/B теста:**
   - Разделение аудитории на группы
   - Равномерное распределение трафика
   - Настройка метрик для измерения
   - Определение длительности теста

3. **Анализ результатов:**
   - Сравнение конверсии между группами
   - Анализ влияния на LTV
   - Оценка ROI каждого варианта
   - Выбор победившего варианта

**📊 Какие данные используются:**
- **💰 Данные о промо** - статистика A/B тестов
- **📊 Аналитические данные** - метрики эффективности
- **👥 Данные об игроках** - поведение в тестовых группах
- **📈 Данные о продажах** - влияние на конверсию и доходы

## 📋 Модели данных Promo/Offer Management

### 💰 Данные о игровых промо и бонусах

**Что хранится:**
- **Название промо** - "Боевой пропуск со скидкой"
- **Тип бонуса** - процент скидки или бесплатные предметы
- **Размер бонуса** - 30% скидки или 5 бесплатных скинов
- **Условия** - минимальная покупка, определенные предметы
- **Ограничения** - количество использований, срок действия
- **Статистика** - сколько раз использовали, какой доход принесли

**Пример данных:**
```
Промокод: "BATTLEPASS30"
Тип: "Процентная скидка"
Размер: "30%"
Условия: "Покупка боевого пропуска, только новые игроки"
Ограничения: "До 28 февраля, максимум 500 использований"
Использовано: "312 раз из 500"
Принесено дохода: "$6,240"
Конверсия: "15.6%"
Средний чек: "$20.00"
```

**Как используется:**
- Для стимулирования покупок в игре
- Для привлечения новых игроков
- Для анализа эффективности игровых бонусов
- Для планирования игровых акций и событий

### 🎯 Данные о промо-кампаниях

**Что хранится:**
- **Название кампании** - "Зимняя распродажа скинов"
- **Тип кампании** - сезонная акция, ретаргетинг, привлечение
- **Целевая аудитория** - сегменты игроков
- **Промо-цепочка** - последовательность предложений
- **Результаты** - метрики эффективности кампании
- **Даты** - период проведения кампании

**Пример данных:**
```
Кампания: "Winter_Skins_2024"
Тип: "Сезонная акция"
Аудитория: "Активные игроки, покупавшие скины"
Участников: "25,000 игроков"
Активных покупателей: "8,750 (35%)"
Доход: "$87,500"
ROI: "340%"
Период: "15-28 декабря 2023"
```

**Как используется:**
- Для планирования будущих кампаний
- Для оптимизации промо-стратегий
- Для расчета ROI промо-активностей
- Для сегментации игроков

### 🎁 Данные о типах предложений

**Что хранится:**
- **Тип предложения** - скидка, бонус, подарок
- **Формат** - процент, фиксированная сумма, предмет
- **Условия активации** - минимальная покупка, категория товаров
- **Ограничения** - лимиты использования, временные рамки
- **Эффективность** - исторические данные по использованию

**Пример данных:**
```
Тип: "Процентная скидка"
Формат: "20% скидка"
Условия: "Покупка от $10, категория 'Скины'"
Ограничения: "Одноразовое использование, 7 дней действия"
Средняя конверсия: "12.5%"
Средний чек: "$18.75"
Популярность: "Высокая среди новых игроков"
```

**Как используется:**
- Для выбора оптимального типа предложения
- Для настройки условий активации
- Для прогнозирования эффективности
- Для создания персонализированных предложений

## 📈 Ключевые метрики Promo/Offer Management

### Метрики использования
- **Redemption Rate** - процент использования промо-кодов
- **Conversion Rate** - конверсия от предложения к покупке
- **Average Order Value** - средний чек с промо
- **Revenue per Promotion** - доход с одного предложения

### Эффективность промо
- **ROI Promotions** - возврат инвестиций в промо-активности
- **Lift in Sales** - прирост продаж от промо
- **Customer Acquisition Cost** - стоимость привлечения через промо
- **Retention Impact** - влияние промо на удержание игроков

### Операционные метрики
- **Time to Create** - время создания нового предложения
- **Promotion Coverage** - охват игроков промо-предложениями
- **A/B Test Success Rate** - успешность A/B тестов
- **Automation Rate** - процент автоматизированных промо

### Качество предложений
- **Personalization Rate** - процент персонализированных предложений
- **Targeting Accuracy** - точность таргетинга предложений
- **Satisfaction Score** - удовлетворенность игроков предложениями
- **Repeat Usage Rate** - частота повторного использования промо
