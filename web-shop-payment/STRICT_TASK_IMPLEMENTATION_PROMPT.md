### 3️⃣ АРХИТЕКТУРНАЯ ВАЛИДАЦИЯ (AI_DECISION_RULES.md)

**Примени все принципы принятия решений:**

#### Принцип 1: Приоритет архитектурной чистоты
- ✅ Clean Architecture - всегда в приоритете
- ✅ Слои не должны нарушаться
- ✅ Dependency Inversion - зависимости направлены внутрь
- ❌ НЕ компрометировать архитектуру ради быстрого решения

#### Принцип 2: Принцип "сначала инфраструктура"
- ✅ Обязательно: `[setup-infrastructure]` перед любыми модулями
- ✅ Проверка: `npm run validate:infrastructure` должен проходить
- ❌ НЕ создавать модули без настроенной инфраструктуры

#### Принцип 3: Стратегия импортов
- ✅ Относительные импорты = везде используем относительные пути
- ✅ Алиас @components/* = ОБЯЗАТЕЛЬНЫЙ для Universal компонентов
- ❌ НЕ использовать другие алиасы

#### Принцип 4: Event-Driven архитектура
- ✅ ТОЛЬКО между модулями = EventBus для межмодульного общения
- ✅ Внутри модуля = прямые вызовы Use Cases/Repository
- ❌ НЕ использовать EventBus внутри модуля

#### Принцип 5: Universal компоненты
- ✅ ОБЯЗАТЕЛЬНЫ для всех View
- ✅ Поддержка фреймворков = React Native/Expo/React Web/Vue/Angular
- ❌ НЕ использовать нативные элементы для базовых UI

#### Принцип 6: Поток данных и архитектурные принципы
- ✅ НЕ путать планирование и выполнение
- ✅ UseCase НЕ вызывает Domain напрямую - только через порты
- ✅ Domain создается и валидируется - но не вызывается как сервис
- ✅ Infrastructure реализует порты - но вызывается через интерфейсы

### 7️⃣ РЕАЛИЗАЦИЯ ПО ПРАВИЛЬНОМУ ПОТОКУ (LOGIC_THINKING_GUIDE.md - Выполнение)

**Используй ВЫПОЛНЕНИЕ (снаружи внутрь):**
```
Interface Adapters → Application → Domain ← Infrastructure
```

#### Правильный поток данных:
1. **UI Event** → View обрабатывает событие пользователя
2. **Presenter** → координирует и вызывает UseCase
3. **UseCase** → координирует через порты (НЕ вызывает Domain напрямую)
4. **Domain** → создается и валидируется (НЕ вызывается как сервис)
5. **Infrastructure** → реализует порты (вызывается через интерфейсы)
6. **Response** → данные возвращаются обратно по слоям
